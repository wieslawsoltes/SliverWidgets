# SliverWidgets Uno Gallery App

Uno desktop app host for the reusable `samples/UnoGallery` gallery page.

## Run

```bash
dotnet run --project samples/UnoGalleryApp/SliverWidgets.UnoGalleryApp/SliverWidgets.UnoGalleryApp.csproj
```

## Build

```bash
dotnet build samples/UnoGalleryApp/SliverWidgets.UnoGalleryApp/SliverWidgets.UnoGalleryApp.csproj
```

The app uses the Uno Platform desktop target and hosts `SliverWidgets.Samples.UnoGallery.UnoGalleryPage`, which demonstrates `ItemsRepeater` fixed-list and grid virtualization, large data realization counters, and CustomScrollView-style composition.
