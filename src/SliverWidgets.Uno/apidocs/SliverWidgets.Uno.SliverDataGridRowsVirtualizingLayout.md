# Summary
Uno `ItemsRepeater` layout for virtualized variable-height DataGrid row containers.

# Remarks
Set `TableWidth` to the full row container width and `RowExtentSelector` to return the per-row height. Call `InvalidateItems()` after replacing the projected row source.
