# Roadmap

SliverWidgets already includes the core protocol, foundational layouts, framework adapters, galleries, tests, packaging, and documentation. Future work should deepen platform integration and measured performance.

## Candidate Work

| Area | Candidate improvement |
|---|---|
| Avalonia | tighter scroll owner integration and richer header animation samples |
| MAUI | device validation matrix and more handler-level collection tuning |
| Uno | renderer-specific verification across supported heads |
| WinUI | Windows runtime CI and packaged gallery artifacts |
| Core | semantic index policies and richer diagnostics |
| Docs | benchmark pages with measured adapter results |

## Release Readiness

Before a stable release:

- lock public API compatibility expectations
- add API XML summaries directly in source or expanded `apidocs`
- publish benchmark methodology
- validate all galleries on target platforms
- add package signing and release notes workflow
